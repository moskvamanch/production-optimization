# Production Optimization using Simulation and Machine Learning

This project focuses on simulation-driven optimization of manufacturing systems using:

- SimPy
- Discrete-event simulation
- Machine learning
- Surrogate models
- Production line optimization

## Current production line

- Cutting
- Drilling
- Sanding
- Assembly
- Painting
- Drying
- Quality control

## Main goal

Optimize production parameters such as:

- buffer capacities
- machine counts
- processing times

to maximize throughput and reduce bottlenecks.
